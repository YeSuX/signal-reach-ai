# Phase 0

Phase 0 是 SignalReach AI 的问题验证与定位收敛阶段。

建议阅读顺序：

1. `phase-0-plan.md`
2. `interview-script.md`
3. `benchmark-template.md`
4. `landing-page-copy.md`
5. `content-calendar.md`

核心目标：

- 完成 15-25 个用户访谈。
- 收集 20 条 benchmark query。
- 完成 3 份手工 demo report。
- 上线 waitlist。
- 找到 3-5 个 design partners。
- 决定是否进入 Phase 1 技术 PoC。
