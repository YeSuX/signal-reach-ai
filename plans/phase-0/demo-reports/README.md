# Demo Reports

本目录保存 Phase 0 的 3 份手工 demo report，用于在产品开发前模拟 SignalReach AI 的最终输出形态。

建议使用方式：

1. 给早期用户展示 report 结构，验证他们是否认可“带证据的人选推荐”。
2. 让用户标记哪些候选对象有价值、哪些不相关。
3. 收集用户对匹配理由、证据、联系方式、外联草稿的反馈。
4. 将用户反馈转成 Phase 1 benchmark 和产品需求。
